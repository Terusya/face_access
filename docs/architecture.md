# Архитектура системы распознавания лиц

## Компоненты и поток данных
Камера (делает снимок и отправляет его) -> 
Edge-узел (Находит лицо, проверяет качество, проверяет не распечатанная ли это фотография. После превращает в набор цифр (эмбеддинг) и отправляет его) ->
Центральный сервер (ищет этот отпечаток в своей БД и при нахождении очень похожего (и с отрывом от второго похожего) отправляет решение пропустить (allow). Иначе отправляет решение ручной проверки охраной (manual_review). Также записывает лог действий) -> 
Если принято решение пропустить, то турникет получает команду для пропуска. Иначе приходит уведомление охраннику.
