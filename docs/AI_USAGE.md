# Использование AI-инструментов

В процессе работы над заданием использовались:
- **DeepSeek**

**Роль AI:**
- Дал больше контекста и идей по использованию камер.
- Предложил готовые библиотеки для будущего улучшения системы распознания лиц.
- Сгенерировал черновики документации для требований, чтобы не забыть какой-либо пункт, указанный в требованиях.

**Проверка безопасности:** 
ИИ предлагал запускать тесты программы сразу на реальных людях. Решение было изменено на обычное логирование с обязательной проверкой с помощью охраны.
