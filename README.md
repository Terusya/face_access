# Face Access System — распознавание лиц на проходной

Система для автоматического распознования и пропуска сотрудников с помощью камеры. Заменяет пропуска, ускоряет вход, снижает нагрузку на охрану.

**Как запустить PoC:**
1. Установите зависимости: "pip install -r requirements.txt"
2. Запустите сервер: "python src/main.py"
3. Отправьте POST-запрос на "/verify" (пример в "src/demo.py").

**Упрощения в PoC:**
- В PoC не используется реальная CV-библиотека для детекции и извлечения эмбеддингов — вместо этого применяется mock-логика, имитирующая успешное распознавание (happy path) и сомнительный случай (risky path) на основе идентификатора события.
- База сотрудников — локальный JSON-файл с mock-эмбеддингами.
- Liveness — mock-проверка.
- Ручная проверка — заглушка (лог + имитация UI).
- Реальная интеграция с турникетом отсутствует.

**Ограничения MVP:**
- Нет распределённого кэширования на edge (все запросы идут к центральному серверу).
- Нет обработки offline-режима (в проде — кеш на edge).
- Нет интеграции с реальным турникетом.
